llmwiki2 (llm-wiki-v2): the open-source LLM wiki engine for Python

A Python library, a command line, a web page and an MCP memory that file your documents into a wiki of linked Markdown notes and answer your questions with citations. Version 1.0.0, the first stable release, came out on 10 November 2026.

By Federico Cesarini and Marco Sassarini · Updated 11 November 2026

llmwiki2 is an open-source Python library, command line, web page and MCP memory that files your documents into a wiki of linked Markdown notes and answers questions citing the notes it used. It is the engine of the Crow desktop app, published from the crow-hq/llm-wiki-v2 repository, by Federico Cesarini and Marco Sassarini.

What is llmwiki2?

llmwiki2 is the PyPI package of LLM Wiki v2, a Python engine for LLM wikis. It summarizes each document into a Markdown note, files the note in a folder about its subject, merges it into the note on the same subject when there is one, links related notes, and answers questions citing the notes it read.

It builds on the LLM wiki idea Andrej Karpathy described. It reads text, Markdown, PDF, Word, PowerPoint, Excel and OpenDocument files, and keeps the wiki as plain Markdown, by default in ~/llm-wiki, in a format derived from Google's Open Knowledge Format, with an untouched copy of every source in raw/.

How do I install llmwiki2?

Install llmwiki2 from PyPI with Python 3.11 or later, using pip install llmwiki2, or uv tool install llmwiki2 if you want uv to fetch Python. Then run llmwiki2: your browser opens, you pick a provider, paste its key, press Test connection, then Save and start.

Install and start
pip install llmwiki2
llmwiki2
With uv
uv tool install llmwiki2

Just looking? llmwiki2 demo opens an example wiki, the notes of a fictional coffee roastery, with no key needed to browse it and its brain. It is copied to ~/llm-wiki-demo. To try it without installing anything but uv:

Example wiki, no key
uvx llmwiki2 demo

The same example wiki is drawn on Crow's home page, where you can explore its brain without installing anything.

How do I use llmwiki2 as a Python library?

Use llmwiki2 as a library by importing Wiki from llmw2, the package's import name. Wiki.from_env reads the settings and the provider's key from the environment; then ingest files a text, ingest_file files a PDF or Office document, and ask returns an answer with its citations. The web page and the command line call the same object.

Python
from llmw2 import Wiki

wiki = Wiki.from_env(bundle="./wiki")        # OKF_* variables and the provider's key, e.g. OPENROUTER_API_KEY
wiki.init()

result = wiki.ingest(open("meeting.md").read(), title="Pricing meeting")
wiki.ingest_file(open("minutes.pdf", "rb").read(), "minutes.pdf")   # also .docx, .pptx, .xlsx, .odt, .ods
print(result.action, result.note, result.created_folders, result.related)

answer = wiki.ask("What did we decide about enterprise pricing?")
print(answer.text, answer.citations)

print(wiki.usage.to_dict())                  # {"llm": …, "classifier": …, "by_model": …}

The same operations are on the command line: llmwiki2 --bundle ./wiki followed by init, ingest, sync, ask, check or serve. Every step of the ingest and ask flows is a function you can replace. The library guide covers the API, and examples/ holds runnable programs.

How do I give Claude Code or Codex a memory with llmwiki2?

To give Claude Code or Codex a memory, install llmwiki2 with the mcp extra, start llmwiki2, open Memory on its page and press Start. The wiki then serves MCP at http://127.0.0.1:8000/mcp: add it with claude mcp add or codex mcp add, and the client recalls from your notes and files what it learns.

Install with the memory
pip install 'llmwiki2[mcp]'      # or: uv tool install 'llmwiki2[mcp]'
Connect a client
claude mcp add --transport http --scope user llm-wiki http://127.0.0.1:8000/mcp   # Claude Code, every project
codex mcp add llm-wiki --url http://127.0.0.1:8000/mcp                            # Codex
MCP toolWhat it does
recallAnswers from the wiki, citing its notes. Read-only.
rememberFiles a text like a note: right folder, merged, linked.
searchFinds notes by their words, with no model call.
read_noteReads one note in full.
rebuildFiles every note again from the raw copies, only with confirm.

Cursor and VS Code take the same URL in their mcp.json. By default the wiki's own models file the memories; the client's models can do it instead, which sends your documents' text to them (see the memory guide). The memory has no authentication: keep the port on your machine.

What is CROW mode?

CROW mode is llmwiki2's default. A small typed classifier takes the filing decisions (which folder, which note it matches, merge or new note, related notes) and reorders the notes found for a question; the LLM writes notes, merges, folder names and answers. When the classifier is not confident enough, or fails, that step goes back to the LLM.

CROW stands for Classifier-Routed Organization of LLM Wikis, the method of the CROW paper. Filing picks a note's folder among every folder of the wiki in one classifier choice; the LLM lays out the folders, with a plan before a batch and a split when a folder grows. Asking, in 1.0.0, starts from the wiki's search: the top note stays first, and one batched classifier call reorders the other 15. The LLM walks the folders only when the search finds nothing.

The default classifier is Jev, by TypeSafe AI, through OpenRouter or TypeSafe; any System One server, such as Laya or Ollama 0.35 or later, can take its place. Classic mode (--mode classic) lets the LLM take every decision. Details: docs/wiki/crow.md.

In the CROW paper's benchmark of 525 documents, CROW read the right note in 89.2% of asks against 61.8% for an LLM taking the same decisions, took 18.4 s per document against 38.6 s, and used 68% fewer LLM tokens. These are the authors' own measurements, on a private corpus of the first author's notes, with the paper's pipeline, before 1.0.0 changed how CROW asks.

Which models and providers does llmwiki2 support?

llmwiki2 talks to any OpenAI-compatible chat API. It has presets for OpenRouter (the default, with google/gemini-3.8-flash), OpenAI, Gemini and Ollama, and a custom setting for any other OpenAI-compatible server, such as vLLM, LM Studio or llama.cpp's server. CROW's classifier is a separate setting: Jev through OpenRouter or TypeSafe, or a local server.

The default models are suggestions and can change in a minor release. Everything can also run on your computer, with writer, classifier and an optional embedder all served by Ollama, at the price of time and some quality.

What changed in llmwiki2 1.0.0?

llmwiki2 1.0.0, released on 10 November 2026, is the first stable release: from here on the library follows semantic versioning, with a documented compatibility scope. A wiki written by 0.8.0 opens as it is, with nothing to convert. In CROW mode, asking now starts from the wiki's search, then one classifier call reorders the notes.

  • Semantic versioning covers the names in llmw2.__all__, the Steps API, the settings, the command line, the HTTP API, the MCP tools and the wiki on disk; not prompt texts, models, thresholds or caches (Compatibility).
  • CROW's ask no longer walks the folders with the classifier.
  • Search with no model call (Wiki.search, the MCP search tool, llmwiki2 search), and an optional embedder.
  • Breaking: four removed settings are ignored with a warning, and over_limit is keyword-only. The rest is in the 1.0.0 release notes.

Is llmwiki2 the same as the LLM Wiki v2 gist?

No. llmwiki2 is installable software: the Python package of the crow-hq/llm-wiki-v2 repository, by Federico Cesarini and Marco Sassarini, released on PyPI. The LLM Wiki v2 gist by Rohit Ghumare, from April 2026, is a separate document with the same name: it extends Karpathy's LLM Wiki pattern with lessons from building agentmemory.

The gist adds ideas such as confidence scores that fade over time, a knowledge graph and hybrid search.

llmwiki2 and Crow

Crow is llmwiki2 as a desktop app for macOS, Windows and Linux, for people who would rather not use a terminal: it finds your documents by itself and works with any model on OpenRouter. Crow does not run local models yet; the engine does, with Ollama. Download Crow, or read what an LLM wiki is.

Questions

Is llmwiki2 free?

Yes. llmwiki2 is free software under the GNU AGPL v3.0 or later: free to use, change and share, also in your own business; if you offer a modified version to others, over a network too, you share its source. The package's licence expression also lists the licences of files it ships, such as its fonts. Cloud models are billed by their provider; Ollama is free.

What is the difference between llm-wiki-v2, llmwiki2 and llmw2?

They are three names for one project. llm-wiki-v2 is the GitHub repository, crow-hq/llm-wiki-v2, whose README is titled LLM Wiki v2. llmwiki2 is the package on PyPI and the command you run. llmw2 is the name you import in Python: from llmw2 import Wiki.

Does llmwiki2 need an API key? Can it run locally with Ollama?

Not necessarily. llmwiki2 demo needs no key to browse, and the LLM can be Ollama on your computer, with no key and no account. CROW's classifier is remote by default (Jev, through OpenRouter or TypeSafe): point it at a System One server on your machine, such as Ollama 0.35 or later or Laya, or use classic mode, where the LLM takes every decision.

Does llmwiki2 work with Obsidian?

The wiki is plain Markdown with relative links and an index.md in every folder, so any editor opens it. Crow, which writes the same format, documents that Obsidian opens its wiki as a vault, graph view included. llmwiki2 does not need Obsidian: its own web page shows the notes and the brain.

Does llmwiki2 need a vector database?

No. llmwiki2's search is BM25 over the notes' words, with no model call. An embedder is optional: with an OpenAI-compatible /embeddings server or Ollama the search goes by meaning too, and the vectors are kept in one file inside the wiki. The notes stay readable Markdown.

How do I cite llmwiki2?

Use the repository's CITATION.cff: Federico Cesarini and Marco Sassarini, llm-wiki-v2, version 1.0.0, released 2026-11-10. It asks you to cite, together with it, the Open Knowledge Format by Google LLC, from which the wiki format is derived. For the method, cite the CROW paper, doi:10.5281/zenodo.22898752.
